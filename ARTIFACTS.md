## 1. Air Shield Planner

**Open locally:** double-click `app/air-shield-planner-en.html`. Data and street map are embedded; internet is needed only for the D3.js library and the Google Fonts (without fonts it falls back to system fonts).

**What’s inside:** Dortmund open data (769 hexagons, 48 candidate sites, 18 hospitals), the optimizer, scenario management (9 presets), failure simulation, cost model, cost of sovereignty. Details: `PROJECT_NOTES.md`, `CALCULATION_METHODS.md`.

**Rebuild after a change:**
```bash
python tools/build_data.py
python tools/build_app.py
node tools/export_csv.js
python tools/export_raw_csv.py
```
- Edit only `app/planner.template.html` (English, the single source).
- `build_app.py` embeds `data/airshield_data.json` and `data/basemap/*` into `app/air-shield-planner-en.html`.
- `export_csv.js` refreshes the model CSV files (raw open-data CSVs: `python tools/export_raw_csv.py`) in `data/export/` with the same code.
- To update the live link, the file has to be republished (ask Claude to publish `app/air-shield-planner-en.html` to the existing link).

**Scenarios** are stored per browser (localStorage); teammates see the 9 presets, not your own changes.
